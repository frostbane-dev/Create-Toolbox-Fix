# Create Toolbox Fix

A small NeoForge mod for Minecraft 1.21.1 that improves and fixes Toolbox behavior in the Create mod.

## Features
* **Empty Toolbox Stacking:** Allows stacking of empty toolboxes.
* **Piston Compatibility:** Pistons can now break/move toolboxes.
* **Dispenser Support:** Dispensers can place toolboxes.
* **Logistic Extraction:** Extract full toolboxes from the logistic system while respecting the exact item contents.

## Bug Fixes
* **Issue #8761:** This mod resolves the issue where toolboxes would remain "ready for request" after being clicked, fixing persistent state bugs.
  * [See original issue here](https://github.com/Creators-of-Create/Create/issues/8761)

## Requirements
* Minecraft 1.21.1
* NeoForge
* Create Mod
