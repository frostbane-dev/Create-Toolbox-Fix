# Create Toolbox Fix

A small NeoForge mod for Minecraft 1.21.1 that fixes an issue where toolboxes and Stock Keepers remain ready for request even after interaction.

## About
This project addresses specific behaviors involving Create's logistics and toolboxes. For more details on the bug being tracked, check out [Create Issue #8761](https://github.com/Creators-of-Create/Create/issues/8761).

## Requirements
* Minecraft 1.21.1
* NeoForge
* Create Mod
